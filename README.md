# Practica-1-Desarrollo-Web-UTP-Introduccion-al-lenguaje-de-programacion-de-PHP
Prácticas introductorias de desarrollo web utilizando PHP y HTML, desarrolladas con Visual Studio Code y ejecutadas mediante WampServer.

En este repositorio encontrarán ejercicios prácticos que realicé como introducción al desarrollo web, utilizando los lenguajes PHP y HTML en el editor de código Visual Studio Code. Verifiqué el funcionamiento de los scripts mediante el servidor local de WampServer.

A través de estos ejercicios prácticos, pude aprender la manera correcta de declarar y utilizar variables, realizar operaciones básicas, trabajar con estructuras condicionales como if y crear formularios simples utilizando HTML y PHP.

Tecnologías y herramientas utilizadas
PHP — Para la programación y procesamiento de los datos.
HTML — Para la creación y estructura de las páginas web.
Visual Studio Code — Editor de código utilizado para desarrollar los ejercicios.
WampServer — Servidor local utilizado para ejecutar y probar los scripts de PHP.
Contenido de las prácticas
Los ejercicios incluidos en este repositorio abarcan conceptos básicos como:

Declaración y uso de variables.
Operaciones matemáticas básicas.
Conversión de unidades.
Estructuras condicionales (if, elseif, else).
Formularios HTML.
Envío y recepción de datos mediante POST.
Uso de funciones básicas de PHP.
Cálculos y procesamiento de datos ingresados por el usuario.
Objetivo
El objetivo de estas prácticas es familiarizarme con los fundamentos de PHP y HTML y desarrollar una base para continuar aprendiendo desarrollo web.
